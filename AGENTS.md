# AGENTS.md

## Working with the User

- Before making changes, confirm the requested work and its scope with the user. Do not start implementation until the user has confirmed.
- Work in small, reviewable steps. After each meaningful step, summarize what changed and ask the user whether to continue or adjust. Do not try to complete a large task in one pass.
- Never assume the user can quickly understand the project or its code. Explain relevant concepts and decisions in clear, approachable language, and avoid unexplained jargon.
- Add friendly Chinese comments to all code you write or modify. Comments should explain the intent or non-obvious behavior, not merely repeat what the code says.

## Keep Solutions Small

- Prefer the simplest implementation that satisfies the confirmed request.
- Avoid introducing new abstractions, dependencies, frameworks, or configuration unless they are necessary.
- Do not propose or build a large architecture by default. Make the smallest useful change, and discuss broader redesigns with the user before pursuing them.
- If the request appears to need a larger solution, explain the trade-offs and propose a small first step for the user to review.
