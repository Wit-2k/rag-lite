# rag-lite 便携版说明

## 怎么用

1. **双击 `RagLite.exe`**。程序会自动在后台拉起自带的 Python 后端（`backend/raglite-backend.exe`），
   约 2 秒后窗口左下角从「正在启动后端…」变成「库内 N 块 / M 个数据源」。
   首次运行会把 .NET 原生库解包到系统临时目录（`%TEMP%\.net\`），比之后慢一两秒；
   个别杀毒软件会拦这一步，若启动失败见下面「常见问题」。
2. **配密钥**：点右上角「**设置**」，把 OpenRouter 密钥粘进「共享密钥」再点「保存并生效」——
   嵌入、重排、回答都用它；也可以在「设置」里分别指定各自的接入点、模型与密钥。
   保存后立刻生效、不用重启（值会写进本目录的 `.env`，手工改那个文件也一样管用）。
   没配密钥也能启动，只是添加数据源和提问会报错，界面顶部会提示缺什么。
3. **建库**：点左侧「批量添加目录…」，**可以一次选多个** **MinerU 客户端解析出来的产物目录**
   （每个都必须有 `full.md`，可以带 `images/`）。程序同时最多导入 3 个目录，超出的排队等待，
   每个目录一行进度，互不影响；同一个目录重复添加不会重复花钱——
   内容没变就直接跳过。
4. **提问**：右下输入框里回车发送，回答会流式显示，命中来源显示在回答上方。
5. **退出**：点右上角关闭键**只是把窗口收进托盘**（后端继续跑，导入不会断）。要彻底退出，
   右键托盘图标选「**彻底退出**」。想再用时，点托盘图标或再双击一次 `RagLite.exe` 就能把窗口叫回来。
   「清空上下文」用于丢弃多轮对话历史（历史默认每轮都带上）。

## 数据放在哪

- 向量库：`data/lancedb/`（跟着这个目录走，整包拷到别的机器也能用）
- 运行日志：`rag-lite-client.log`（界面出问题先看它；后端日志也转发在里面）
- 配置：`.env`（**别把它发给别人**，里面有你的密钥）

## 可以调的配置

**推荐在界面右上角「设置」里改**（保存即生效）；下面这些是等价的 `.env` 写法，手工改完需要重启程序。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `OPENROUTER_API_KEY` | 空 | 三个角色共享的密钥 |
| `EMBED_BASE_URL` / `EMBED_MODEL` / `EMBED_DIM` / `EMBED_API_KEY` | OpenRouter / voyage-multimodal-3.5 / 2048 | 嵌入用的接入点、模型、维度、独立密钥 |
| `RERANK_BASE_URL` / `RERANK_MODEL` / `RERANK_API_KEY` | OpenRouter / voyageai/rerank-3 | 重排 |
| `CHAT_BASE_URL` / `CHAT_MODEL` / `CHAT_API_KEY` | OpenRouter / google/gemini-2.5-flash | 回答模型（任意 OpenAI 兼容端点） |
| `RETRIEVE_TOP_K` / `CONTEXT_N` | 20 / 3 | 先召回多少条、重排后送给大模型几条 |
| `RAGLITE_PORT` | 17650 | 后端监听端口，被占用会自动顺延 |

⚠ **换嵌入模型要注意**：维度写进了向量库的结构里。
- 只换模型、维度不变：在左侧重新添加一遍原目录，程序会自动重新向量化（列表里会先标出「需重新导入」）。
- 维度也变了：必须重建库——把 `data/` 删掉（或改名留底）再重新导入。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 启动后没有任何窗口 / 立刻退出 | 看同目录 `rag-lite-client.log` 末尾的报错；若提到找不到 `libSkiaSharp` 之类的原生库，多半是杀毒软件拦了首次解包——把本目录加入白名单后重试 |
| 窗口显示「后端启动失败」 | 看同目录 `rag-lite-client.log` 末尾的报错；确认 `backend/raglite-backend.exe` 还在（杀毒软件有时会拦） |
| 提示「没有配置 OPENROUTER_API_KEY」 | 点右上角「设置」直接填（推荐）；或在本目录建 `.env` 填 `OPENROUTER_API_KEY=...`——**写完会自动生效，不用重启**（界面顶部还会显示该改哪个文件） |
| 点了关闭键，程序好像还在跑 | 这是有意的：关窗只是收进托盘，后端继续运行。要彻底退出请右键托盘图标选「彻底退出」 |
| 托盘里找不到图标 | Windows 11 默认把**新**托盘图标放进「隐藏的图标」溢出区（点任务栏那个向上小箭头）；把它拖到任务栏上就会常驻显示 |
| 再双击一次 RagLite.exe 没反应 | 已经在运行了：程序是单实例的，第二次启动会把已有窗口叫到前台，然后自己退出（不会起第二个后端） |
| 添加目录时提示「目录里没有 full.md」 | 选的是产物目录本身，不是它的上一级；文本解析要在 MinerU 客户端先做完 |
| 任务管理器强杀了界面 | 不用手动清后端：界面一死，作业对象与看门狗会把后端一起收尾（实测 0.5 秒内端口就释放）；下次双击照常用 |
| 提示「这个数据源已经在导入队列里了」 | 同一个目录正在导入（或排队）时又添加了一次；等它跑完即可，重复导入本来就不花钱 |
| 一次选了十几个目录 | 只有 3 个在跑，其余显示「排队中…」；想改上限就设 `MAX_PARALLEL_IMPORTS` 后重启 |
| 提示向量库维度不一致 | 见上面「换嵌入模型要注意」 |
| 想换端口 | 在 `.env` 里改 `RAGLITE_PORT`（端口冲突时后端会自动往后找一个） |

## 目录结构

```
RagLite.exe            界面程序（单文件：自包含 .NET 运行时 + 界面依赖，不需要另装 .NET）
backend/               自带的 Python 后端（PyInstaller 打的，不需要另装 Python）
  raglite-backend.exe
  _internal/           后端依赖（pyarrow / lancedb / chonkie 等）
data/                  运行后生成的向量库（可备份、可整包搬走）
zh-Hans/               .NET 运行时的中文本地化资源
.env.example           配置模板
使用说明.txt            本文件
```
